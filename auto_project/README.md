## Setup Instructions
1. **Clone the repository**
2. **Install dependencies** for both frontend (Next.js) and backend (FastAPI)
3. **Run the backend**:
   ```bash
   cd backend
   pip install -r requirements.txt
   uvicorn main:app --reload
   ```
4. **Run the frontend**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
5. **Access the app** at `http://localhost:3000`
