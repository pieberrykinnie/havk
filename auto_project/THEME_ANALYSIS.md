# HAVK: Hacking the Desert - THEME ANALYSIS

## Theme
Survive and Innovate in Resource-Scarce Environments
- Focus: Software solutions for scarcity (water, food, energy, healthcare, digital equity, resource distribution)
- Open-ended: Any impactful solution to scarcity

## Prizes
- 1st Place: HAVK Certificate + Special Discord Role
- 2nd Place: HAVK Certificate
- 3rd Place: HAVK Certificate

## Deadline
- Submission Deadline: July 18, 2025 @ 1:00pm CDT

## Judging Criteria
- Technical Depth (Weight: 10)
- Creativity (Weight: 10)
- Usability (Weight: 5)
- Accessibility (Weight: 10)
- Fun Factor (Weight: 5)
- Visuals/UI-UX (Weight: 5)

## Requirements
- 5-Minute Video Presentation (YouTube or file-sharing link)
- GitHub Repository (all code must start from hackathon start date, clear commit messages, good README)
- Project Description (what, who, how, why)

## Constraints
- Software only (no hardware)
- Students only, above legal age of majority
- All countries/territories except standard exceptions
- Entrants retain IP, but HAVK gets non-exclusive license to display/share
- Submissions provided "AS IS"

## Inspiration Areas (Optional)
- Food/water scarcity tech
- Supply chain resilience
- Uplifting marginalized communities
- Smart resource management
- Bio-hacks for agriculture
- Emergency tech for climate migration
