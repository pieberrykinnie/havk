# Translation & i18n Workflow (Weblate)

IrrigaBot supports multilingual NLU and messaging. To streamline translation:

## Workflow
1. All user-facing strings (bot responses, dashboard UI) are extracted to YAML/JSON files in `locales/`.
2. [Weblate](https://weblate.org/) is used for collaborative translation:
   - Project maintainers upload source files.
   - Contributors translate via the Weblate web UI.
   - Pull requests are auto-generated for new/updated translations.
3. On merge, CI syncs `locales/` and triggers a redeploy.

## Adding a New Language
- Add a new file: `locales/<lang>.yml` (e.g. `hi.yml` for Hindi)
- Translate all keys.
- Submit via Weblate or PR.
